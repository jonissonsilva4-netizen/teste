# Pet&Co. — Loja de produtos para pets

Página de vendas responsiva feita com HTML, CSS e JavaScript puro.

## O que já está pronto
- Página inicial com banner e apresentação da loja
- Categorias para cães, gatos, brinquedos e cuidados
- Vitrine com produtos de demonstração
- Carrinho funcional com quantidade, remoção e subtotal
- Finalização de pedido pelo WhatsApp
- Layout adaptado para celular e computador

## Como personalizar
1. Edite os produtos, preços e imagens no array `products` de `script.js`.
2. Ao clicar em finalizar pedido, a página solicita o número de WhatsApp da loja com DDI e DDD. Exemplo: `5511999999999`.
3. Troque o nome Pet&Co. pelo nome definitivo da sua loja em `index.html`.

## Como publicar grátis com GitHub Pages
1. Abra **Settings** do repositório.
2. Entre em **Pages**.
3. Em **Build and deployment**, escolha **Deploy from a branch**.
4. Selecione a branch `main` e a pasta `/ (root)`, depois clique em **Save**.
5. Aguarde a publicação. O endereço ficará no formato `https://jonissonsilva4-netizen.github.io/teste/`.

Os produtos e preços são exemplos demonstrativos; substitua pelos itens reais da loja antes de vender.
